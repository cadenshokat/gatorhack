# National Park Service: "Basic Information - Biscayne National Park" (study copy)

A frozen copy of the NPS page as a phone sees it, made for a private, non-commercial usability study.

- **Source:** https://www.nps.gov/bisc/planyourvisit/basicinfo.htm, captured 2026-10-27 with an iPhone user agent at 390 CSS px.
- **Text and NPS photos:** works of the US federal government, public domain in the US (17 U.S.C. 105). Credit:
  National Park Service.
- **NPS Arrowhead:** a protected emblem of the National Park Service (18 U.S.C. 701; 36 CFR 11). It appears only
  because it is part of the copied page inside a private research study; no endorsement is implied. Ask NPS before
  any wider use.
- **Fonts (self-hosted from the page's own CSS):** Inter (SIL OFL 1.1), Open Sans and Open Sans Condensed (Apache 2.0 /
  SIL OFL 1.1), Source Sans Pro (SIL OFL 1.1), Font Awesome 4 (SIL OFL 1.1, CSS MIT), Video.js icon font (Apache 2.0),
  slick (MIT).
- **US Web Design System CSS and icons:** public domain (CC0) where written by the US government; see
  https://github.com/uswds/uswds.
- **Changes:** site scripts and trackers removed; section, menu and search toggles re-created by a local script;
  the DOI chat embed left inert (its iframe loads nothing); all files stored locally; in the study's adapted
  condition, WebAble changes the page's presentation.
